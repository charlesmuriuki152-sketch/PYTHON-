# Lab 02: Variables and Data Types

## Objective

The objective of this lab is to understand how Python stores information using variables and how different types of data are represented.

## What I Learned

In this lab, I learned:

- How to create variables in Python.
- The difference between strings, integers, floats, and booleans.
- How to display variable values using the `print()` function.
- How to check the data type of a variable using the `type()` function.

## Python Code

```python
device = "smart phone"
ip_address = "10.3.6.1"
number_of_login_attempts = 5
compatible = True

print(device)
print(ip_address)
print(number_of_login_attempts)
print(compatible)

print(type(device))
print(type(ip_address))
print(type(number_of_login_attempts))
print(type(compatible))
```

## Expected Output

```
smart phone
10.3.6.1
5
True
<class 'str'>
<class 'str'>
<class 'int'>
<class 'bool'>
```

## Key Takeaways

- Variables store information.
- Strings store text.
- Integers store whole numbers.
- Floats store decimal numbers.
- Booleans store `True` or `False`.
- The `type()` function helps identify the data type of a variable.
