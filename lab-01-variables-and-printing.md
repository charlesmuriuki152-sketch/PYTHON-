# 🧪 Lab 1: Variables and Printing

## Objective

Practice creating variables and displaying information using the `print()` function.

## Learning Outcomes

- Create variables.
- Store text and numbers in variables.
- Display information using the `print()` function.
- Print text together with variables.

## Task 1

Create variables for:

- Name
- Age
- Country

Print each variable on a separate line.

## Task 2

Using variables, print the following information:

My name is Charles.
I am 23 years old.
I live in Kenya.

## Task 3

Create variables for:

- Dream career
- Favorite programming language
- Favorite operating system

Print all the variables.

## Task 4

Create a variable named `goal` and store the following value:

Become a cybersecurity engineer.

Print the value of the variable.

## Challenge

Create five additional variables containing personal information of your choice and print them.

Examples:

- University
- GitHub username
- Favorite Linux distribution
- Favorite hobby
- Future certification

## Success Criteria

- Variables are created correctly.
- Information is displayed using `print()`.
- Text and variables are combined correctly.
- The program runs without errors.

## Conclusion

This lab provides practical experience with Python variables and the `print()` function. These concepts form the foundation of all future Python programs and cybersecurity automation scripts.
